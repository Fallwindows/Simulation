# Storyboard reference assets

These are the 12 original user-supplied storyboard images, in shot order. Their original bytes are preserved under descriptive filenames. `manifest.json` maps every renamed file to its original upload, dimensions, SHA-256 checksum, and shot interval.

Use the inner scene for composition comparisons; panel headers, borders, timestamps, and bottom captions are production notes, not default film graphics. Keep originals unchanged. Additional review crops must be labeled as derived images.

The references contain illustrative numerical values, some repeated IDs, generated text artifacts, and concept-copy claims. Follow `../SIMULATION_VIDEO_IMPLEMENTATION_SPEC.md` for correcting those without redesigning the approved visual concept. The master specification is one level above this directory.
